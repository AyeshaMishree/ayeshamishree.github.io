EmoCare

Smart Mental Health Application with AI and Therapist Support

EmoCare is Ayesha's idea for one of Pakistan's first integrated AI and therapist mental health platforms. It was built to be accessible, affordable, and culturally relevant, addressing rising psychological challenges among students, professionals, and teenagers in Pakistan. It combines AI-driven emotional support, smart journaling, mood-based analytics, and verified therapist connectivity with secure in-app payment, inside a single, privacy-conscious ecosystem.

Overview

The project follows an incremental, modular methodology. The founding team continuously integrated new modules and validated them through internal review, supervisor feedback, and consultation with domain experts in clinical psychology, all while maintaining strict privacy and security protocols around sensitive mental health data.

Findings from the project showed that pairing AI-driven self-help tools with verified therapist support and server-side payment confirmation meaningfully improves accessibility, personalization, and continuity of care compared to the fragmented digital mental health tools already on the market, most of which skip verified therapist integration, secure payment, or crisis-escalation paths entirely.

Architecture

EmoCare runs on a modular three-tier architecture, with an Android front end, an ASP.NET Core backend, and a Python FastAPI AI microservice, all sharing Firebase Firestore as a common source of truth.

Two-stage AI pipeline

Stage A: a locally hosted, fine-tuned BERT classifier (BertForSequenceClassification) predicts the user's mental state from journal or chat text.
Stage B: that label is passed to a remote LLM call via OpenRouter (openai/gpt-oss-120b:free), which generates a short CBT-inspired reply or coping recommendation.

A hard-coded safety branch short-circuits to a crisis message whenever the classifier returns "suicidal," and a set of canned empathetic fallback responses covers any failure of the LLM call, so the system degrades gracefully rather than silently.

The Android app serves both patients and therapists from a single APK, with the correct role dispatched at runtime from a role document in Firestore. Local reminders, a daily motivational quote, journaling nudges, and a weekly check-in, are scheduled entirely on-device using Android WorkManager, with no push server required.

Key Features

  • AI Chatbot Therapist (Premium). 24/7 CBT-based conversations, context-aware using journal and mood history.
  • Smart Journaling with Sentiment Analysis. Each entry returns a predicted emotional state and a tailored recommendation.
  • Mood Tracker with Insights. Weekly and monthly visual trend graphs across emotional states.
  • Therapist Integration. Document-based verification, admin approval, session booking, and secure Stripe payment.
  • In-App Chat and Audio/Video Calls. Kommunicate SDK for messaging, WebRTC for live sessions.
  • Mindfulness & Self-Care Toolkit. Guided audio, meditation videos, and reading material, no appointment needed.
  • Role-Based Privacy. Patient, therapist, and admin access enforced at both the Firebase rules layer and the backend.
  • Therapist Earnings & Withdrawal. Therapists can review paid sessions and request payouts directly in-app.
